# ESP32 + LCD 1602 — многофункциональный дисплей

Автономное устройство на базе **ESP32** и символьного дисплея **LCD 1602A (16×2)**, которое показывает сетевую информацию, Unix-время, пинг и системные показатели. Умеет засыпать для экономии энергии и просыпаться по кнопке.

## Возможности

- 🔁 **4 режима**, переключаемых кнопкой **BOOT** по кругу.
- 🌐 **Стартовый сетевой экран** — IP / MAC / hostname (автоматическая ротация).
- ⏱️ **Unix-время**, синхронизированное по NTP.
- 📶 **Пинг** до `ya.ru` (настоящий ICMP, среднее по 3 пакетам).
- 📊 **Системная информация** — температура чипа, тактовая частота, занятая RAM, качество Wi-Fi (RSSI).
- 💤 **Автосон** через 10 секунд бездействия и пробуждение по кнопке BOOT.
- 💡 Подсветка дисплея, приглушённая до ~6% (программный ШИМ).

## Железо

| Компонент | Описание |
|---|---|
| **ESP32** | Плата NodeMCU-32S (Ai-Thinker ESP-32S), 38 пинов |
| **LCD 1602A** | Символьный дисплей 16×2 на контроллере HD44780 |
| **I2C-модуль** | Адаптер на PCF8574 (синяя плата с 4 контактами), адрес **0x27** |

> Определено по факту: чип **ESP32-D0WD-V3** (rev 3.1), 240 МГц, Wi-Fi + BT, dual-core, MAC `a0:a3:b3:2b:63:04`.

### Схема подключения (I2C-модуль → ESP32)

| Синяя плата I2C | ESP32 |
|---|---|
| **GND** | **GND** |
| **VCC** | **5V** (VIN) |
| **SDA** | **GPIO21** (на плате может быть `P21` / `IO21` / `D21`) |
| **SCL** | **GPIO22** (аналогично `P22` / `IO22` / `D22`) |

```
        ESP32 NodeMCU-32S
      ┌───────────────────┐
      │  ·  ·  ·  ·  ·   │
      │  IO21 ── SDA      │──→ синяя плата I2C
      │  IO22 ── SCL      │
      │  5V   ── VCC      │
      │  GND  ── GND      │
      └───────────────────┘
```

⚠️ **Важно:** подписи пинов на разных клонах отличаются (`P21`/`D21`/`IO21` — всё одно и то же, номер = номер GPIO). Ищи по цифре.

## Режимы работы

Переключение — короткое нажатие кнопки **BOOT** (GPIO0). Порядок:

| # | Режим | Что показывает |
|---|---|---|
| 0 | **Сеть** (стартовый) | IP-адрес → MAC → hostname (листается каждые 3 с) |
| 1 | **Unix time** | Текущий Unix-timestamp, тикает каждую секунду |
| 2 | **Ping ya.ru** | RTT в мс, обновляется раз в секунду |
| 3 | **Система** | `T:45C 240M 45%` + бар качества Wi-Fi |

**Детали:**
- Пинг — настоящий ICMP (через `esp_ping`/`ping_sock.h`), среднее по 3 пакетам, поэтому одиночная потеря не даёт ложный «timeout».
- MAC показывается без двоеточий (`A0A3B32B6304`), т.к. полный `AA:BB:...` (17 симв.) не влезает в строку из 16 символов.
- Hostname задаётся в конфиге (по умолчанию `esp32-lcd`).

## Сборка и прошивка

### Зависимости (библиотеки)

| Библиотека | Версия | Назначение |
|---|---|---|
| `LiquidCrystal_I2C` | 1.1.4 | работа с LCD через PCF8574 |
| `Wire` | 2.0.0 | I²C |
| `WiFi` | 2.0.0 | Wi-Fi |
| `time` (встроенная) | — | NTP-синхронизация |
| `ping/ping_sock.h` (ESP-IDF) | — | ICMP-пинг |

Установка библиотеки LCD через Arduino CLI:

```bash
arduino-cli lib install "LiquidCrystal I2C"
```

### Прошивка

Плата: **ESP32 Dev Module** (FQBN `esp32:esp32:esp32`), ядро `esp32:esp32@2.0.14`.

Через **Arduino CLI** (порт может отличаться):

```bash
arduino-cli compile --fqbn esp32:esp32:esp32 unix_time
arduino-cli upload -p /dev/cu.usbserial-0001 --fqbn esp32:esp32:esp32 unix_time
```

Через **Arduino IDE**: выбери плату «ESP32 Dev Module», открой `unix_time/unix_time.ino`, нажми Upload.

## Конфигурация

**Wi-Fi логин и пароль** хранятся в файле `unix_time/secrets.h` (он в `.gitignore` и не попадает в репозиторий):

1. Скопируй `unix_time/secrets.h.example` → `unix_time/secrets.h`.
2. Впиши свои данные:
   ```cpp
   #define WIFI_SSID "ВАШ_WIFI_SSID"
   #define WIFI_PASS "ВАШ_ПАРОЛЬ"
   ```

Остальные настройки — в начале файла `unix_time/unix_time.ino`:

```cpp
const char* PING_HOST = "ya.ru";      // хост для пинга
const char* HOSTNAME  = "esp32-lcd";  // hostname устройства
```

Прочие параметры (внутри кода):

| Параметр | Где | По умолчанию |
|---|---|---|
| Таймаут сна | `SLEEP_AFTER` | 10000 мс (10 с) |
| Интервал ротации сетевого экрана | `NET_PAGE_INTERVAL` | 3000 мс |
| Яркость подсветки | ШИМ в `loop()` | ~6% (`150/2100 мкс`) |
| Интервал пинга | `PING_INTERVAL` | 1000 мс |

> 🔒 Учётные данные Wi-Fi вынесены в `unix_time/secrets.h` (в `.gitignore`). Не добавляй пароли/токены в коммиты — используй `secrets.h`.

## Питание

### Вариант 1 — USB (проще всего)

Любой USB-источник 5 В (зарядка телефона, пауэрбанк, USB-порт) в разъём платы.

### Вариант 2 — Li-ion аккумулятор

```
[USB зарядка] → TP4056 IN
TP4056 BAT → 18650 (+/−)
TP4056 OUT+ → выключатель → MT3608 IN+
TP4056 OUT− → MT3608 IN−
MT3608 OUT+ → ESP32 5V (VIN)
MT3608 OUT− → ESP32 GND
```

- **18650**: Samsung INR18650-35E (3500 мАч) или Panasonic NCR18650B (3400 мАч), flat-top **без защиты** (защиту даёт TP4056 с чипом DW01).
- **MT3608** — обязательно настрой на **5.0 В** мультиметром **до** подключения ESP32.

### Вариант 3 — Солнечная панель

Солнечная панель **5 В / 2 Вт** подключается вместо USB к `TP4056 IN`. Устройство работает от батареи-буфера, панель подзаряжает её днём.

### Автономность (18650 на 3500 мАч)

| Режим | Ток | Время |
|---|---|---|
| Работа (без сна) | ~130 мА | ~17 ч |
| Со сном | ~20–25 мА | ~4–5 дней |
| Со сном + солнечная панель | — | месяцы |

> Потолок экономии задаёт обвязка платы (USB-serial CP2102 + стабилизатор AMS1117 ≈ 15–25 мА), а не сам ESP32.

## Устранение неполадок

| Симптом | Причина / решение |
|---|---|
| Подсветка горит, но текста нет | Покрути **синий потенциометр** (контраст) на плате |
| Экран пустой, но по I²C адрес находится | Проверь пайку синей платы к LCD (холодная пайка данных D4–D7/E/RS) |
| «WiFi FAILED» | Проверь SSID/пароль в `secrets.h` (убедись, что имя сети и пароль без опечаток) |
| Пинг всегда «timeout» | Хост не отвечает на ICMP или сеть блокирует пинг; попробуй `8.8.8.8` |
| Пробуждение по BOOT ненадёжно | Используется лёгкий сон (не глубокий) — GPIO0 является страп-пином |
| Мерцание подсветки при пинге | Ограничение программного ШИМ; лечится заменой резистора подсветки |
| Адрес LCD не `0x27` | Может быть `0x3F` — проверь I²C-сканером |
